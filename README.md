# 🎨 Demo Project: Art Gallery

This is a demo project called **Art Gallery**.  
It showcases artworks using data from the Art Institute of Chicago API.

👉 [API Documentation](https://api.artic.edu/docs/)

---

## 🚀 Features

- Display of artworks from a public art API
- Pagination for navigating between result pages
- Search functionality by painter name and picture title
- Ability to save personal notes per artwork using Local Storage
- Responsive layout
- Clean and minimal UI

---

## 🛠 Tech Stack

- Tailwind CSS
- TypeScript
- Zod (Schema-based validation)
- React (useState, useEffect, useContext, React Router)
